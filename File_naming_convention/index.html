Exposome variables file naming convention

File names for Exposome variables follow a format that includes standardized metadata elements in a predictable order. This table shows the components that make up a name. Visit exposome.uu.nl for visualization and more information.

For example, the file called: TEMP_AVG_20201201_v3.tif is the average temperature raster for December 1, 2020, which was modeled in 2022. The file called NO2B100_AAV_XX_XX_05_v2.tif represents the annual average of NO2 in a 100 meter buffer for 2005, as modeled in 2022.
